## 📂 Projetos

### 🔟 [NotaDez – Sistema de Gestão de Notas para Docentes](https://github.com/Cadu-Marins/ES-PI-2025-T3-G11)
*Projeto Integrador II – Engenharia de Software, PUC-Campinas (2025) · Projeto em grupo (Time G11, 3 integrantes)*

Aplicação web para docentes do ensino superior gerenciarem, de forma particular, as notas de seus estudantes. Permite cadastrar instituições, disciplinas e turmas, importar alunos e calcular automaticamente a nota final (média aritmética ou ponderada).

- **Alunos:** cadastro manual ou importação em massa via CSV
- **Notas:** componentes de avaliação flexíveis (P1, P2, trabalhos) e lançamento em grade
- **Relatórios:** exportação das notas em CSV
- **Segurança:** autenticação com JWT e recuperação de senha por e-mail
- **Tecnologias:** HTML5, CSS3, JavaScript, Node.js, TypeScript, Express, Oracle Database, Multer, CSV-Parser, Nodemailer

### 🗳️ [LAD.Py – Sistema de Votação Digital](https://github.com/GabrielAlbasini/ES-PI1-2026-T103-G01)
*Projeto Integrador I – Engenharia de Software, PUC-Campinas (2026) · Projeto em grupo (6 integrantes)*

Backend de um sistema de votação digital executado via terminal, que integra Lógica de Programação em Python, banco de dados SQL e conceitos de Álgebra Linear aplicados à proteção da informação.

- **Módulo de Gerenciamento:** cadastro, edição, remoção e listagem de eleitores e candidatos, com validação matemática de CPF e Título de Eleitor, geração de chave de acesso e criptografia de dados sensíveis
- **Módulo de Votação:** abertura da urna, registro de votos, encerramento, auditoria por logs de ocorrências e exibição de resultados
- **Gestão do projeto:** Git/GitHub e GitHub Projects para controle de versão e tarefas
- **Tecnologias:** Python, MySQL, mysql.connector
